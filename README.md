# Skinfold support site

Public website, privacy policy, and technical support for the free iOS app **Skinfold**.

- English (default and fallback): <https://ywhdt.github.io/body-fat-calculator-site/>
- 简体中文: <https://ywhdt.github.io/body-fat-calculator-site/zh-Hans/>
- 日本語: <https://ywhdt.github.io/body-fat-calculator-site/ja/>

The explicit English path at <https://ywhdt.github.io/body-fat-calculator-site/en/> remains available alongside the canonical English root URL.

The site is static, contains no advertising or analytics scripts, and does not receive measurement data from the app. Each supported language includes its own privacy-policy and support pages.
