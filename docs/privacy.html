隐私政策

生效日期：2026 年 7 月 11 日

体脂率计算不要求注册，不包含广告或分析服务，也不会把你的测量数据发送给开发者或第三方。

1. 本政策的适用范围

本政策适用于“体脂率计算”iOS 应用（Bundle ID：com.ywhdt.bodyfatcalculator）。

2. 应用在设备上处理的信息

为了完成计算和本地记录，应用会在你的设备上处理你主动输入或选择的性别、年龄、三处皮褶读数，以及由此计算出的体脂率、分类、测量日期和复测提示。

这些信息仅在应用的本地沙盒中使用。它们不会被发送给开发者，不会用于追踪、广告、用户画像或跨应用识别，也不会出售或共享给第三方。

3. 输入与本地历史记录

应用不会自动持久化你在计算页填写的性别、年龄或皮褶读数。只有在你完成计算后主动点击“保存到历史”，应用才会把该次结果写入设备上的本地历史；应用不会在后台自动创建记录或云端副本。

4. 数据收集与网络服务

开发者不运营用于接收本应用数据的服务器。应用没有账号系统、广告 SDK、第三方分析 SDK或远程健康数据库，当前版本也不接入 HealthKit。按照 Apple 对 App 隐私标签中“收集”的定义，本应用选择“不收集数据”。

5. 删除信息

你可以在“历史记录”页面删除单条记录，或点击“清空”并确认后删除全部历史。本地历史文件已被排除在系统备份之外；删除应用可以移除其保存在设备应用容器内的其余数据。已经存在的旧备份及应用删除行为仍由你的 iOS 与 Apple 账号设置控制。

6. 儿童隐私

本应用的估算模型面向成年人使用。应用不会建立账号或收集儿童的个人信息；未成年人不应依赖本应用作出健康决定。

7. 网站

本隐私政策与支持页面是无广告、无分析脚本的静态页面。它们托管于 GitHub Pages；访问网站时，GitHub 可能为提供和保护该服务处理必要的网络请求信息。应用内的测量数据不会发送到本网站或 GitHub。

8. 政策更新

如果应用的数据处理方式发生实质变化，本页面会先更新说明与生效日期，并同步更新 App Store 隐私标签。历史版本可通过项目仓库的提交记录核对。

9. 联系方式

对本政策或数据处理有疑问，请发送邮件至 ywhdt_zh@outlook.com，或在 GitHub Issues 提交问题。请不要在公开 Issue 中附上个人健康信息。
